# Выбор адреса и ближайшего магазина: что доработать на бэкенде

При первом заходе в каталог открывается окно «Укажите ваш адрес». После выбора адреса в хедере на всех страницах появляется плашка с ним (клик — снова выбор адреса).

## Файлы

| Файл | Что внутри |
|---|---|
| `catalog.html` (и `catalog/*`, `kz/…`) | Разметка окна `[data-address-modal]` |
| Все страницы, хедер | Плашка `[data-address-pill]` |
| `src/lib/address.js` | Логика окна и плашки + заглушка `mock` |
| `src/styles/address.css` | Стили |

## Контракт

Чтобы подключить настоящие данные, до `address.js` определите `window.flexAddressApi` с двумя методами (иначе работает заглушка `mock` из того же файла):

### `suggest(query) → Promise<string[]>`
Подсказки адресов по введённой строке (геокодер/справочник адресов). Пустой массив → под полем «Адрес не найден. Проверьте название улицы или номер дома».

### `nearestStore(address) → Promise<{ id, name } | null>`
Ближайший магазин для выбранного адреса. `null` → экран «Не удалось подобрать магазин» с кнопкой «Изменить адрес».

## Что сохраняется

`localStorage.flex_address = { address, storeId, store }`. После выбора на `document` летит событие `flex:address` с этими данными — по нему каталог должен перезагрузить наличие.

Наличие в карточке каталога: атрибут `data-stock="out"` на `.product-card` + плашка `.product-card__badge--stock` «Нет в наличии». Сейчас проставлено вручную у «Бежевый Песок» для примера.

## Когда окно открывается
- первый заход в каталог, если адрес ещё не выбран (после закрытия крестиком — снова в следующей сессии браузера);
- `/catalog?address` — открыть принудительно (на это ведёт плашка с других страниц);
- клик по плашке в хедере на странице каталога.

## Заглушка (для проверки)

| Ввод | Результат |
|---|---|
| `Алматы, Абая 25` | 5 подсказок, после выбора — магазин найден, плашка «пр. Абая, 25» |
| Любая строка с `9999` | «Адрес не найден» |
| Город не Алматы, например `Астана, Кенесары 10` | «Не удалось подобрать магазин» |

Сбросить выбранный адрес: в консоли `flexAddress.clear()`.
